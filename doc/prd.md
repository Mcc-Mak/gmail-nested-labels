# PRD（產品需求文件）

## 1. 產品願景

提供一套輕量、免費的 Gmail 自動分類工具，讓使用者無需設定 OAuth2 或
付費 API，即可自動依寄件者網域標記郵件並以 AI 進行主題分析。

## 2. 功能需求

### FR-1：IMAP 連線
- 以應用程式密碼透過 IMAP 連線 Gmail。
- 連線失敗時顯示明確錯誤訊息。

### FR-2：郵件擷取
- 擷取最新 N 封收件匣郵件（N 可由 `-n` 參數或 `EMAIL_COUNT` 環境變數設定）。

### FR-3：清除標籤
- 移除每封郵件上 `\Inbox` 以外的所有現有標籤。

### FR-4：扁平網域標記
- 取寄件者網域，反轉各部分，以 `-` 接合成扁平標籤。
- 範例：`hko.gov.hk` -> `hk-gov-hko`。
- 標籤不存在時以 IMAP `CREATE` 建立。
- 若存在舊 `/` 格式標籤衝突（Gmail 將 `-` 與 `/` 視為等價），
  自動刪除舊標籤後重試建立。

### FR-5：封存
- 標記成功後以 `STORE \Deleted` + `EXPUNGE` 從 INBOX 移除郵件（等同
  Gmail 封存，使用者標籤保留在「全部郵件」中）。
- `--no-archive` 旗標可停用封存（除錯模式）。

### FR-6：AI 主題分析
- 將郵件主旨與內文傳給 OpenCode 模型進行主題分組。
- 輸出至 `themes-ai.json`。

### FR-7：CI/CD
- 推送到 `dev-001` 自動合併至 `dev` -> `main`，無人工審批。

## 3. 非功能需求

| 編號 | 需求 |
|------|------|
| NFR-1 | 免 Google Cloud Console、免 API 金鑰、免信用卡 |
| NFR-2 | 以 `venv` 隔離 Python 環境 |
| NFR-3 | 批次處理以減少 IMAP 伺服器往返 |
| NFR-4 | 驗證標籤套用結果（重新擷取 `X-GM-LABELS`） |
| NFR-5 | 全專案繁體中文本地化 |

## 4. 限制與假設

- 假設使用者已啟用 Gmail 兩步驟驗證。
- 假設 `opencode` CLI 已安裝且可用。
- IMAP 速率限制可能影響大量郵件處理。
